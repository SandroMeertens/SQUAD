# SQUAD — De Klunzenstad

Een coöperatieve 3D-klunzengame in ontwikkeling voor groep 8. Deze repository bevat de voorbereide zelfstandige Firebase-versie, inclusief offline 3D-oefenstand, multiplayerfuncties en tests.

**Status:** code in ontwikkeling. Firebase is nog niet gekoppeld of gepubliceerd. Voor gebruik met leerlingen zijn beveiliging, privacy, leraarbeheer en tests met 30 iPads nog nodig.
